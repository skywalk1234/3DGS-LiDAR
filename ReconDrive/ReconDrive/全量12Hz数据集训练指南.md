# 全量 12Hz 数据集训练指南

> 用途：把 ReconDrive 代码从 mini 数据集切换到 **nuScenes 全量 12Hz 插值数据集**（`interp_12Hz_trainval`）训练。
> 本文档说明：①前置条件 ② 需要改哪些地方 ③代码侧已做的适配 ④注意事项。

---

## 一、前置条件（缺一不可）

### 1. 12Hz 插值数据集 `interp_12Hz_trainval` 必须已存在


```bash
/path/to/nuscenes/
├── samples/                 # keyframe 传感器数据
├── sweeps/                  # 非 keyframe sweep 数据
├── maps/
├── interp_12Hz_trainval/    # ★ 必须有：scene/sample/sample_data/ego_pose/
│                            #   calibrated_sensor/sensor/... 全套 json 表
└── v1.0-trainval/           # （标准版可保留，用于对比/测试）
```


### 2. 权重文件

模型 `__init__` 时就加载，缺失会直接报错：

| 文件 | 大小 | 说明 |
|---|---|---|
| `checkpoints/vggt.pt` | ~2.5 GB | VGGT backbone 预训练权重 |
| `checkpoints/sam2.1_hiera_small.pt` | ~150 MB | SAM2 分割（训练时懒加载） |

`checkpoints/` 在本机是一个软链接 → `/data/public_data/ReconDrive_checkpoint`。 机器上需要建同样的软链接，或把权重文件放进 `checkpoints/` 目录。

## 二、需要改哪些地方

### 1. 配置文件：直接用新的 `configs/nuscenes/recondrive_12hz.yaml`

仓库里已经新增了 `configs/nuscenes/recondrive_12hz.yaml`（mini 配置不动）。 只需要改这一个文件里的 **2 个路径**（文件里已用 `★ 必改` 标出）：

```yaml
data_cfg:
  data_path: '/path/to/nuscenes'          # 改成 服务器的全量数据根目录
  cache_dir: '/path/to/cache/nuscenes-12hz'  # 改成大磁盘路径（深度图缓存 50-100GB）
```

⚠️ 缓存的实际写入位置是 `<cache_dir 的父目录>/samples/DEPTH_MAP/`（`generate_depth_map` 逻辑），所以**父目录也要有足够的空间和写权限**。

其余关键项已经配好，**不需要 改**：

```yaml
data_cfg:
  nuscenes_version: 'interp_12Hz_trainval'   # 全量 12Hz 版本
  context_span: 6                            # 窗口 = frame 0 + 6 帧后
  with_sweeps: false                         # sweep 监督关闭
  num_workers: 8

model_cfg:
  frame_rate: 12                             # 与 context_span=6 配套，窗口时长 0.5s
  use_sweep_supervision: false               # 12Hz 下用中间关键帧监督，不开 sweep
```

### 2. 训练命令

 当前命令（mini 用的）：

```bash
CUDA_VISIBLE_DEVICES=2,3,4 CUDA_PATH=/usr/local/cuda-12.8 TORCH_CUDA_ARCH_LIST="8.9;9.0" python scripts/trainer.py \
    --cfg_path configs/nuscenes/recondrive.yaml \
    --pretrained_ckpt /data/mr/project/ReconDrive/ReconDrive/checkpoints/recondrive_stage2.ckpt \
    --train_4d --devices 3 \
    --ckpt_dir /data/mr/project/ReconDrive/ReconDrive/work_dirs/recondrive_training/ckpt5 \
    --save_last_only
```

切 12Hz 后只需要改 3 处：

```bash
CUDA_VISIBLE_DEVICES=2,3,4 CUDA_PATH=/usr/local/cuda-12.8 TORCH_CUDA_ARCH_LIST="8.9;9.0" python scripts/trainer.py \
    --cfg_path configs/nuscenes/recondrive_12hz.yaml \      # ① 换成 12Hz 配置
    --pretrained_ckpt <权重路径> \                     # ② 换成 机器上的 checkpoint
    --train_4d --devices 3 \
    --ckpt_dir <输出目录> \                            # ③ 换成 机器上的目录
    --save_last_only
```

改动点说明：
- **① `--cfg_path`**：必须换成 `recondrive_12hz.yaml`，否则还是读 mini 配置（2Hz / context_span=1）
- **② `--pretrained_ckpt`**：路径是 机器上的绝对路径。可以是官方 `recondrive_stage2.ckpt`，也可以是 自己训的 `best_module.ckpt`（`load_pretrained_checkpoint` 是 non-strict 加载，shape 不匹配的参数会跳过）
- **③ `--ckpt_dir`**： 机器上的输出目录
- `--devices 3` 配合 `CUDA_VISIBLE_DEVICES=2,3,4`：用 3 张卡， 按自己机器调整
- `--save_last_only`：只存 `last.ckpt` / `best_module.ckpt`，并在 20/40/60/80 epoch 额外存快照（`EpochScheduledCheckpoint`），省磁盘

## 四、注意事项

1. **时间语义**：`frame_rate: 12` + `context_span: 6` → 窗口时长 `6 × 1/12 = 0.5s`。车辆 flow 线性插值（`context_span_delta = context_span × frame_step_s`）就用这个时长，配错了时间会乱。
2. **sweep 监督不要开**：12Hz 中间关键帧本身已经是监督目标（上面第 3 节），`use_sweep_supervision` / `with_sweeps` 保持 `false`。mini 上那套"中间靠 raw sweep 填"的思路在 12Hz 下不需要。
3. **显存**：`batch_size: 1` 已最小。12Hz 每步渲染 6 帧 × 6 相机，比 mini（平均 ~2 帧）重约 3 倍。`accumulate_grad_batches=2`（trainer 里写死），显存不够就把卡数/epoch 调整一下，不要动 batch_size。
4. **首轮会缓存**：深度图缓存（`<cache_dir父目录>/samples/DEPTH_MAP/`）首次全量生成 50-100GB，耗数小时；第二次开始直接命中。
5. **val 指标**：12Hz 下 validation 用全部 7 帧算指标（比 mini 只算 frame 0 重），单 epoch 时间会长一些。
6. **测试集**：`vggt4dgs_dataset.py` 里 `stage=='test'` 的测试场景是硬编码的全量场景（scene-0014/0098/...），在全量数据上存在，训练结束后的 `trainer.test()` 会正常跑。如果 用 mini 测试这批场景会为空（不影响训练）。
7. **`train_epoch: 120`**：全量 700 场景 × 120 epoch 量很大（文档里 10 epoch 8 卡约 2-3 天）。如果 时间有限，建议按需下调（比如 20-40），或用 `--save_last_only` 的 20/40/60/80 快照机制选最好的继续。
